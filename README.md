# Kodigo Website

Sitio corporativo de **Kodigo**. El proyecto vivo está en [`kodigo-web/`](./kodigo-web/).

## Cómo arrancar

```bash
cd kodigo-web
npm install
npm run dev
```

Ver [`kodigo-web/README.md`](./kodigo-web/README.md) para los comandos completos, estructura y reglas del proyecto.

## Estado y documentos

Toda la documentación operativa (PRD, plan de adaptación, despliegue, brief) vive dentro de `kodigo-web/docs/`.
